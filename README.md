# Canva Design Masterclass

Design clear, on-brand visuals in Canva in one hands-on day — from the communication brief, typography and layout through colour, storyboards and task flows to critique, iteration and a multi-format brand campaign.

## About the course

You work in Canva all day on image-based exercises. You turn a communication need into a visual brief and layout, build a type hierarchy, and control colour, form and image treatment. You then plan storyboards and task flows, audit designs against a rubric, run structured peer critique, and finish by adapting one message across several formats in a collaborative brand campaign. Every lab ends with acceptance criteria, so each output is checked before you move on.

## Learning outcomes

- **LO1** — Develop visual communication projects in Canva by blending typography with media elements.
- **LO2** — Create and evaluate Canva storyboards and task flows using visual-design best practices.
- **LO3** — Develop collaborative enhancement strategies that improve visual communication effectiveness.
