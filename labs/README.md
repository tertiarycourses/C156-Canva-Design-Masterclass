# Canva Design Masterclass — Labs

**Course code:** C156
**Version:** v1.0 · 30 September 2026

Each lab is self-contained. Open its folder, read the guide, and work with the supplied PNG/JPEG image assets in Canva. Save all outputs inside the same lab folder or your trainer-approved workspace.

## Lab sequence

1. [Lab 01 — Visual Brief and Layout Exploration](lab-01-visual-brief-layout/README.md) — Translate a communication need into a visual brief and two layout directions.
2. [Lab 02 — Typography Hierarchy and Message Control](lab-02-typography-hierarchy/README.md) — Create a readable three-level type system and apply it to an awareness visual.
3. [Lab 03 — Colour and Form Mood Board](lab-03-colour-form-moodboard/README.md) — Build a controlled mood board that communicates a brand personality through colour, shape and image treatment.
4. [Lab 04 — Product Advertisement Design](lab-04-product-advertisement/README.md) — Integrate product imagery, forms, typography and colour into a persuasive advertisement.
5. [Lab 05 — Storyboard Sequence](lab-05-storyboard-sequence/README.md) — Create an annotated storyboard that communicates a short visual narrative to collaborators.
6. [Lab 06 — Task Flow Design](lab-06-task-flow/README.md) — Model a visual-production workflow with clear actions, decisions and end states.
7. [Lab 07 — Aesthetic and Functional Audit](lab-07-aesthetic-functional-audit/README.md) — Evaluate a design with a shared rubric and propose specific enhancements.
8. [Lab 08 — Peer Review and Iteration](lab-08-peer-review-iteration/README.md) — Use structured comments and version comparison to improve a design collaboratively.
9. [Lab 09 — Multi-Format Campaign Adaptation](lab-09-multi-format-campaign/README.md) — Recompose one message across formats while preserving brand recognition and hierarchy.
10. [Lab 10 — Collaborative Brand Campaign Capstone](lab-10-brand-campaign-capstone/README.md) — Integrate brief, mood board, advertisement, storyboard, critique and enhancement strategy into one coherent campaign.
