# Lab 01 — Visual Brief and Layout Exploration

**Course:** Canva Design Masterclass (`C156`)
**Version:** v1.0 · 30 September 2026

## Scenario

Create a workplace heat-exhaustion awareness visual that can be understood quickly by staff.

## Objective

Translate a communication need into a visual brief and two layout directions.

## Supplied image files

- `heat-exhaustion-template.png`
- `layout-reference-01.png`
- `layout-reference-02.png`

## Detailed procedure

1. Open the supplied template image and create a new Canva design that matches its aspect ratio.
2. Write a one-sentence brief naming audience, primary message, action and viewing context.
3. Create a named baseline page before editing.
4. Build Layout A with a dominant warning headline, one focal image area and a clear action zone.
5. Duplicate the page and create Layout B by changing only the grid and focal position.
6. Run a five-second hierarchy test with a partner and record the first three items noticed.
7. Select the stronger direction, state why it fits the brief and export a high-quality JPEG.

## Evidence to retain

Brief, two layout variants, five-second test note and final JPEG.

## Acceptance criteria

- [ ] The primary message is noticed first.
- [ ] Alignment and spacing follow a repeatable grid.
- [ ] The action is visible without competing elements.
- [ ] The final image exports at the intended size.

## Reflection prompts

- Which decision most improved the message or focal hierarchy?
- Which visible design decision most improved the audience's understanding?
- What source, permission or provenance evidence must accompany the finished image?
