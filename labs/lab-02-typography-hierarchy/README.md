# Lab 02 — Typography Hierarchy and Message Control

**Course:** Canva Design Masterclass (`C156`)
**Version:** v1.0 · 30 September 2026

## Scenario

Refine the heat-exhaustion communication so headline, symptoms and action read in the correct order.

## Objective

Create a readable three-level type system and apply it to an awareness visual.

## Supplied image files

- `type-reference-03.png`
- `type-reference-05.png`
- `type-reference-06.png`

## Detailed procedure

1. Duplicate the approved Lab 1 design and rename the page Lab02-Typography.
2. Define display, heading and body type roles before choosing fonts.
3. Limit the system to two type families or one family with controlled weights.
4. Set headline scale and contrast so it wins the five-second test.
5. Adjust body size, line length, leading and alignment for the viewing context.
6. Check punctuation, capitalization and wording for consistency.
7. Test the design at 100%, thumbnail size and grayscale.
8. Export the final design as JPEG and capture a type-style reference page.

## Evidence to retain

Final JPEG plus a type-style reference showing font roles and settings.

## Acceptance criteria

- [ ] Three type levels are visibly distinct.
- [ ] Body copy remains readable at target size.
- [ ] No more than two font families are used.
- [ ] Typography supports rather than competes with the message.

## Reflection prompts

- Which decision most improved the message or focal hierarchy?
- Which visible design decision most improved the audience's understanding?
- What source, permission or provenance evidence must accompany the finished image?
