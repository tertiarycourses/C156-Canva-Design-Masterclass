# Lab 08 — Peer Review and Iteration

**Course:** Canva Design Masterclass (`C156`)
**Version:** v1.0 · 30 September 2026

## Scenario

Review a Lakehouse menu or social tile and close accepted feedback actions.

## Objective

Use structured comments and version comparison to improve a design collaboratively.

## Supplied image files

- `breakfast.jpeg`
- `caprese-salad.jpeg`
- `club-sandwich.jpeg`
- `lakehouse-logo.png`

## Detailed procedure

1. Create a branded menu or social tile from the supplied food images and logo.
2. Name the first complete page v1-Baseline.
3. Share for comment or simulate a comment review with a partner.
4. Request feedback on hierarchy, colour, typography, imagery and brand consistency.
5. Classify each comment as accept, clarify or decline and record a reason.
6. Duplicate the baseline as v2-Revised and implement accepted changes.
7. Resolve or close each accepted comment only after verifying the result.
8. Export a before/after JPEG board and retain the decision log.

## Evidence to retain

Baseline, revised version, comment decision log and before/after JPEG.

## Acceptance criteria

- [ ] Feedback refers to explicit criteria.
- [ ] Every accepted comment is traceable to a revision.
- [ ] Baseline remains preserved.
- [ ] The revised design remains recognisably on-brand.

## Reflection prompts

- Which decision most improved the message or focal hierarchy?
- Which visible design decision most improved the audience's understanding?
- What source, permission or provenance evidence must accompany the finished image?
