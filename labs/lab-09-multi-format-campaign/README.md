# Lab 09 — Multi-Format Campaign Adaptation

**Course:** Canva Design Masterclass (`C156`)
**Version:** v1.0 · 30 September 2026

## Scenario

Adapt a Lakehouse campaign into square post, vertical story and presentation slide formats.

## Objective

Recompose one message across formats while preserving brand recognition and hierarchy.

## Supplied image files

- `chocolate-cup.jpeg`
- `couple-lunch.jpeg`
- `lakehouse-secondary-dark.png`
- `smartphone-cafe.jpeg`

## Detailed procedure

1. Define one campaign message and call-to-action.
2. Build the square post as the source composition.
3. Create vertical-story and 16:9 presentation variants.
4. Recompose rather than stretch: adjust crop, line breaks, spacing and focal position per format.
5. Keep palette, type roles, logo handling and image treatment consistent.
6. Check safe areas and reading order for each format.
7. Place all three variants on a review board and explain the controlled differences.
8. Export each format and the review board as JPEG.

## Evidence to retain

Three format JPEGs plus a comparison board.

## Acceptance criteria

- [ ] All formats preserve the primary message.
- [ ] No image or logo is stretched.
- [ ] Hierarchy is appropriate to each aspect ratio.
- [ ] The family is visually consistent across channels.

## Reflection prompts

- Which decision most improved the message or focal hierarchy?
- Which visible design decision most improved the audience's understanding?
- What source, permission or provenance evidence must accompany the finished image?
